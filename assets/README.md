# Assets

Reference material for matching the film look. The `reference/` stills and GIFs are third-party film frames and fan captures: they are not part of the repository (gitignored), so the rows below only record where each came from. `tools/checks/check_film.py` and `tools/dev/measure_reference.py` use them when present and skip them otherwise. `digital_rain/glyphs.py` loads `rezmason/Matrix-Code.ttf` and the two Resurrections atlases (`rezmason/resurrections_msdf.png` and `rezmason/resurrections_glint_msdf.png`), which ship with the build; the other files are reference only. See `design/film-reference.md` for how each file is used.

The 14 `matrix-2003-*` stills were downloaded 10 November 2026 for design/film-reference-reloaded.md; same rules as above (measurement only, not bundled). No Reloaded or Revolutions motion clip was found, so there is no 2003 gif.
